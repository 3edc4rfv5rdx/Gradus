# Gradus

**A plain weather forecast for Android: now, the week ahead, and hour by hour.**

![Android 11+](https://img.shields.io/badge/Android-11%2B-3DDC84?logo=android&logoColor=white)
![Kotlin](https://img.shields.io/badge/Kotlin-Compose-7F52FF?logo=kotlin&logoColor=white)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

Work in progress: the app's frame is in place, the forecast itself is not yet.

## Screens

- **Now**: current weather and the days ahead.
- **Hourly**: the forecast hour by hour, grouped by day.
- **Settings**: theme, colour, language, and the update check at launch.

## Building

The numbered scripts in the project root drive the build; `AGENTS.md` describes
how they fit together.
